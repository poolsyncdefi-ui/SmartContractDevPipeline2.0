1. Introduction et architecture

1.1. Qu'est-ce que le Smart Contract Dev Pipeline ?

Le pipeline est un outil d'ingénierie assistée par IA pour le développement de smart contracts Solidity. Il intègre :

  • Compilation via Foundry (Forge)
  • Tests unitaires (Foundry)
  • Analyse statique (Slither)
  • Vérification formelle (Halmos)
  • API REST pour l'orchestration
  • Interface Web (Dashboard) pour la validation humaine

4. Boucle de développement

4.1. Structure d'un contrat

Placez vos contrats dans le dossier contracts/. Exemple : contracts/Counter.sol

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract Counter {
    uint256 public count;

    function increment() public {
        count += 1;
    }

    function decrement() public {
        require(count > 0, "Counter: count underflow");
        count -= 1;
    }
}

4.2. Écrire des tests Foundry

Placez vos tests dans test/. Exemple : test/Counter.t.sol

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import "forge-std/Test.sol";
import "../contracts/Counter.sol";

contract CounterTest is Test {
    Counter public counter;

    function setUp() public {
        counter = new Counter();
    }

    function test_Increment() public {
        counter.increment();
        assertEq(counter.count(), 1);
    }

    function test_Decrement() public {
        counter.increment();
        counter.decrement();
        assertEq(counter.count(), 0);
    }

    function test_DecrementRevertsWhenZero() public {
        vm.expectRevert("Counter: count underflow");
        counter.decrement();
    }
}

4.3. Exécuter les tests

# Lancer tous les tests
forge test

# Lancer un test specifique
forge test --match-test test_Increment

# Avec traces detaillees
forge test -vvvv

5.2. Vérification formelle avec Halmos

Créez un fichier de test symbolique test/CounterSym.t.sol :

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.33;

import {Test} from "forge-std/Test.sol";
import {Counter} from "../contracts/Counter.sol";

contract CounterSymTest is Test {
    Counter public counter;

    function setUp() public {
        counter = new Counter();
    }

    function check_increment(uint256 x) public {
        vm.assume(x < type(uint256).max);
        uint256 current = counter.count();
        counter.increment();
        uint256 next = counter.count();
        assert(next == current + 1);
    }
}

8.2. Exemple : Test ERC20 avec Foundry

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import "forge-std/Test.sol";
import "../contracts/MyToken.sol";

contract MyTokenTest is Test {
    MyToken public token;

    function setUp() public {
        token = new MyToken(1000 * 10**18);
    }

    function test_InitialSupply() public {
        assertEq(token.totalSupply(), 1000 * 10**18);
        assertEq(token.balanceOf(address(this)), 1000 * 10**18);
    }

    function test_Transfer() public {
        address recipient = address(0x123);
        token.transfer(recipient, 100 * 10**18);
        assertEq(token.balanceOf(recipient), 100 * 10**18);
    }
}

10. Processus après redémarrage du poste

10.1. Démarrage rapide (1 minute)

💡 Le script de démarrage start_pipeline.ps1 existe déjà et est prêt à l'emploi.
  1. Lancer Docker Desktop 
    # Lancer Docker Desktop depuis le menu Démarrer
# Attendre que l'icône devienne verte (barre d'état système)
  2. Lancer le pipeline 
    cd D:\Web3Projects\20260817_SmartContractDevPipeline2.0
.\start_pipeline.ps1
    ✅ Ce script exécute automatiquement :
    • La vérification de l'environnement (Python, Docker, Foundry, Slither, Halmos)
    • L'activation de l'environnement virtuel (avec tests de validation intégrés)
    • Le nettoyage et le redémarrage des services Docker (Redis, PostgreSQL)
    • Le lancement d'Anvil dans un nouveau terminal
    • La vérification de tous les services (API, Redis, PostgreSQL, Anvil)
    • La validation du code Solidity (forge build, forge test, slither, halmos)
    • Le lancement de l'API FastAPI
