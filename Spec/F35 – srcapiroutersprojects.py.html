1. Classes, Structures de Données et Méthodes Implémentées

Le module src/api/routers/projects.py implémente le routeur REST FastAPI dédié à la gestion complète du cycle de vie des projets de smart contracts, faisant le pont entre les requêtes HTTP, la persistance asynchrone et le moteur d'orchestration d'agents.

Endpoints de Création & Consultation Unitaire
  • create_project(payload: ProjectCreateRequest, db: AsyncSession) : Route POST / permettant de créer un nouveau projet, de persister ses spécifications YAML en BDD et d'amorcer le pipeline via l'ArchitectAgent.
  • get_project(project_id: str, db: AsyncSession) : Route GET /{project_id} permettant de récupérer les détails complets d'un projet à partir de son identifiant UUID.
Endpoints de Listing, Filtrage & Recherche
  • list_projects(...) : Route GET / gérant le listing paginé avec filtres multi-critères (statut, priorité, catégorie, chain, tags) et tri dynamique.
  • search_projects(query: str, ...) : Route GET /search dédiée à la recherche textuelle avancée sur le nom, la description et les spécifications des projets.
Endpoints de Mise à Jour & Contrôle du Statut
  • update_project(project_id: str, payload: UpdateProjectRequest, ...) : Route PUT /{project_id} pour la mise à jour partielle des métadonnées du projet.
  • update_project_status(project_id: str, status: str, ...) : Route PATCH /{project_id}/status permettant de faire évoluer explicitement le statut métier d'un projet (ex: IN_PROGRESS, COMPLETED, FAILED).
  • delete_project(project_id: str, ...) : Route DELETE /{project_id} pour l'archivage ou la suppression logique du projet et de ses artefacts associés.

2. Bonnes Pratiques Appliquées

  • Injection de Dépendances Asynchrones : Utilisation systématique du pattern Depends(get_async_db) pour fournir une session SQLAlchemy asynchrone non-bloquante (AsyncSession) à chaque requête.
  • Découplage DTO / Modèle ORM : Séparation stricte entre la couche de données (ProjectModel) et les objets d'échange API (ProjectCreateRequest, ProjectResponse), validés automatiquement via Pydantic.
  • Gestion Normalisée des Erreurs HTTP : Levée explicite d'exceptions typées (ex: HTTPException(status_code=404, detail="Project not found")) assurant un retour d'erreur homogène au client.
  • Asynchronisme Natif & Non-Bloquant : Opérations BDD intégralement asynchrones via await db.commit(), await db.refresh() et await db.get() pour une montée en charge optimale.

3. Points Remarquables

  • Intégration Moteur d'Orchestration (Event-Driven) : La création d'un projet ne se limite pas à la BDD ; elle prépare l'instanciation du WorkflowEngine et du composant ArchitectAgent pour déclencher la génération automatique des contrats.
  • Génération Univoque d'Identifiants : Attribution automatique d'UUID v4 pour garantir l'unicité globale des identifiants de projet dans tout le pipeline distribué.
  • Routage Modulaire FastAPI : Déclaration isolée via APIRouter(prefix="/projects", tags=["projects"]) facilitant l'inclusion dans l'application principale et la génération automatique de la documentation OpenAPI / Swagger.

from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.ext.asyncio import AsyncSession
from src.db.database import get_async_db
from src.models.project import ProjectModel, ProjectStatus
from src.api.schemas.requests import ProjectCreateRequest
from src.api.schemas.responses import ProjectResponse
from src.orchestration.workflow_engine import WorkflowEngine
from uuid import uuid4

router = APIRouter(prefix="/projects", tags=["projects"])

@router.post("/", response_model=ProjectResponse)
async def create_project(
    payload: ProjectCreateRequest,
    db: AsyncSession = Depends(get_async_db)
):
    """Crée un projet et initialise l'ArchitectAgent."""
    project = ProjectModel(
        id=str(uuid4()),
        name=payload.name,
        spec_yaml=payload.spec_yaml,
        status=ProjectStatus.CREATED
    )
    db.add(project)
    await db.commit()
    await db.refresh(project)
    
    # À implémenter : déclencher l'ArchitectAgent
    # engine = WorkflowEngine()
    # await engine.run_pipeline()
    
    return ProjectResponse(
        id=project.id,
        name=project.name,
        status=project.status.value,
        created_at=project.created_at
    )

@router.get("/{project_id}", response_model=ProjectResponse)
async def get_project(
    project_id: str,
    db: AsyncSession = Depends(get_async_db)
):
    """Récupère un projet par son ID."""
    project = await db.get(ProjectModel, project_id)
    if not project:
        raise HTTPException(status_code=404, detail="Project not found")
    return ProjectResponse(
        id=project.id,
        name=project.name,
        status=project.status.value,
        created_at=project.created_at
    )
