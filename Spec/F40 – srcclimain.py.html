1. Classes, Structures de Données et Fonctions Implémentées

Le module src/cli/main.py sert de point d'entrée principal pour l'application CLI. Il initialise l'environnement, gère le logging structuré/coloré, orchestre la gestion des profils de configuration, suit les métriques d'exécution et capture globalement les exceptions.

Logging & Gestion des Couleurs ANSI
  • configure_cli_logging(verbose, quiet) : Configure dynamiquement les niveaux de log (DEBUG, ERROR, INFO) et applique le formateur coloré via colorlog avec dégradation gracieuse en cas d'absence du paquet.
  • Colors : Classe d'utilitaire contenant les constantes de codes couleur ANSI (HEADER, BLUE, GREEN, WARNING, FAIL, etc.) et la méthode enabled() vérifiant si la sortie supporte les couleurs (test TTY et variable NO_COLOR).
  • color_text(text, color), success(), error(), warning(), info(), header() : Helpers de formatage rendant le texte coloré de manière conditionnelle.
Gestion des Profiles de Configuration
  • load_profile(profile_name) : Recherche et charge un profil JSON de configuration (dans ~/.pipeline/ ou ./.pipeline/) et met à jour dynamiquement le singleton settings.
  • save_profile(profile_name) : Exporte la configuration actuelle du pipeline au format JSON (en masquant les secrets) dans le répertoire utilisateur.
Contexte & Métriques d'Exécution
  • CliContext : Classe de contexte partagée entre toutes les commandes Click pour enregistrer le temps d'exécution (start_time), le nombre de commandes exécutées, les erreurs rencontrées et les drapeaux d'environnement.
  • pass_context : Décorateur Click personnalisé assurant la transmission de l'instance CliContext.
Commandes Principales & Groupes
  • cli(...) : Groupe principal Click recevant les options globales (--verbose, --quiet, --profile, --no-color, --json-logs, --version).
  • help(ctx) : Affiche une aide avancée et formatée avec la liste de toutes les commandes et des exemples concrets.
  • version(ctx) : Affiche les informations de version du pipeline, la version Python ainsi que l'environnement courant.
  • profile / profile_list / profile_create / profile_load / profile_delete : Sous-groupe et commandes de gestion CRUD des profils.
  • metrics(ctx) : Affiche l'uptime et le bilan des commandes/erreurs de la session CLI.
Gestion des Exceptions & Point d'Entrée
  • handle_exception(exc, ctx) : Intercepte et formate proprement les erreurs métier (PipelineError avec détails JSON), les interruptions utilisateur (Ctrl+C) et les exceptions imprévues.
  • main() : Point d'entrée exécutable instanciant le contexte, exécutant la CLI Click et interceptant globalement les codes de sortie.

2. Bonnes Pratiques Appliquées

  • Respect des Standards Terminal (NO_COLOR & TTY) : Détection automatique du support couleur via sys.stdout.isatty() et respect strict de la norme d'accessibilité NO_COLOR.
  • Injection de Contexte Click : Utilisation d'un objet CliContext centralisé évitant le recours aux variables globales pour stocker l'état et les métriques de session.
  • Gestion Avancée des Exceptions : Séparation claire entre les erreurs d'utilisation (Click), les erreurs métier contrôlées (PipelineError) et les exceptions fatales avec affichage de stacktrace uniquement en mode debug.
  • Hiérarchie des Profils : Support de la surcharge des configurations par ordre de priorité (Défaut → Fichier Profil Global/Local → Variables d'Environnement → Flags CLI).

3. Points Remarquables

  • Système de Profiles Intégré : Possibilité de switcher instantanément d'environnement (ex: dev, staging, production) sans altérer le code source ni réécrire les variables système.
  • Architecture Modulaire Extensible : Rattachement des commandes filles distantes du module src.cli.commands via cli.add_command(commands_cli) tout en conservant le contrôle global du cycle de vie dans main.py.
  • Affichage Conditionnel Gracieusement Dégradé : Auto-détection de la présence de la bibliothèque colorlog avec basculement automatique sur un formateur standard sans planter l'application.

# src/cli/main.py
import click
import logging
import sys
import os
import json
import time
from pathlib import Path
from typing import Optional, Dict, Any

from src.cli.commands import cli as commands_cli
from src.config.settings import settings, reload_settings
from src.core.exceptions import PipelineError

VERSION = "2.0.0"
CLI_NAME = "pipeline"

class CliContext:
    def __init__(self):
        self.start_time = time.time()
        self.commands_executed = 0
        self.errors = 0
        self.metrics: Dict[str, Any] = {}

    def get_uptime(self) -> float:
        return time.time() - self.start_time

pass_context = click.make_pass_decorator(CliContext, ensure=True)

@click.group()
@click.option('--verbose', '-v', is_flag=True, help='Verbose output')
@click.option('--quiet', '-q', is_flag=True, help='Quiet output')
@click.option('--profile', '-p', help='Load configuration profile')
@click.option('--no-color', is_flag=True, help='Disable colored output')
@click.version_option(version=VERSION, prog_name=CLI_NAME)
@pass_context
def cli(ctx: CliContext, verbose: bool, quiet: bool, profile: Optional[str], no_color: bool):
    """Smart Contract Dev Pipeline - CLI Tool."""
    if no_color:
        os.environ['NO_COLOR'] = '1'
    if profile:
        load_profile(profile)

# Inclusion du groupe de commandes distantes
cli.add_command(commands_cli)

def main():
    ctx = CliContext()
    try:
        cli(obj=ctx)
        ctx.commands_executed += 1
    except Exception as e:
        handle_exception(e, ctx)
        sys.exit(1)

if __name__ == "__main__":
    main()
