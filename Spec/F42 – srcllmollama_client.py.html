1. Classes, Structures de Données et Fonctions Implémentées

Le module src/llm/ollama_client.py constitue l'implémentation concrète de l'interface LLM dédiée à l'interaction avec une instance Ollama locale. Il gère l'inférence textuelle, la génération vectorielle (embeddings), le streaming, la gestion du cache et la télémétrie complète du service.

Classe Principale & Méthodes Exposées
  • OllamaClient(LLMClient) : Client d'inférence asynchrone héritant de la classe de base abstraite LLMClient.
    • __init__(base_url, model, embedding_model, ...) : Initialisation avec paramétrage fin des timeouts, nombre de retries, configurations du cache et des modèles par défaut.
    • generate(prompt, system_prompt, ...) : Génération de texte synchrone/asynchrone supportant l'ensemble des hyperparamètres (temperature, top_p, top_k, repeat_penalty, num_ctx, num_gpu).
    • generate_stream(prompt, system_prompt, ...) : Inférence en mode streaming renvoyant un iterateur asynchrone (AsyncIterator[str]) de tokens.
    • embed(text, use_cache) : Calcul de l'empreinte vectorielle d'un texte avec vérification et mise en cache MD5 temporisée (TTL).
    • embed_batch(texts, use_cache) : Traitement parallèle par lots de plusieurs textes via asyncio.gather.
    • get_embedding_cache_stats() / clear_embedding_cache() : Inspection des métriques du cache (hit rate, taille) et vidage des entrées.
    • health_check() / health_check_detailed() : Diagnostic réseau rapide et audit détaillé incluant le statut de disponibilité des modèles requis.
    • list_models(), get_model_info(), pull_model(), delete_model() : Méthodes d'administration du cycle de vie des modèles Ollama locaux.
    • get_stats() : Extraction des métriques cumulatives de performance, latences moyennes et statistiques réseau.
    • close() / Context Manager (__aenter__, __aexit__) : Gestion propre de la fermeture des sessions HTTP et libération des ressources.

2. Bonnes Pratiques Appliquées

  • Gestion Avancée du Client HTTP (httpx.AsyncClient) : Utilisation d'un client HTTP asynchrone unique réutilisé pour limiter le coût de poignée de main TCP, complété par une configuration granulaire des timeouts (connect, read, write, pool).
  • Résilience & Retry avec Exponential Backoff : Mécanisme automatique de rejeu sur échec de connexion ou timeout avec temporisation exponentielle, évitant la saturation du serveur.
  • Caching Performant des Embeddings : Empreinte MD5 des requêtes textuelles avec validation TTL pour éviter de réexécuter des inférences vectorielles coûteuses lors de recherches répétitives.
  • Gestion d'Exceptions Explicites : Capture fine des erreurs HTTP et dissociation claire entre erreurs de connexion (LLMConnectionError), erreurs de réponse (LLMResponseError) et échecs généraux (LLMError).
  • Architecture Non-Bloquante : Emploi de générateurs asynchrones natifs (async for) pour la restitution fluide token par token lors de la génération.

3. Points Remarquables

  • Health Check Détaillé et Mode Dégradé : Capacité à détecter si le serveur Ollama est opérationnel mais ne possède pas le modèle spécifié par défaut, basculant l'état du diagnostic en degraded.
  • Télémetrie Temporelle Intégrée : Recueil dynamique des temps moyens de génération et d'embedding permettant un suivi fin de la latence du système local au fil de l'eau.
  • Support complet d'Administration des Modèles : Intégration du téléchargement en streaming (pull_model) avec fonctions de callback pour suivre l'avancement du chargement des poids.

# src/llm/ollama_client.py
import httpx
import json
import asyncio
import hashlib
from typing import Optional, List, Dict, Any, AsyncIterator, Union, Callable
from datetime import datetime
import logging

from src.llm.llm_client import LLMClient
from src.config.settings import settings
from src.core.exceptions import LLMConnectionError, LLMResponseError, LLMError

logger = logging.getLogger(__name__)

class OllamaClient(LLMClient):
    """Client Ollama pour l'inférence LLM locale et la gestion des embeddings."""

    def __init__(
        self,
        base_url: Optional[str] = None,
        model: Optional[str] = None,
        embedding_model: Optional[str] = None,
        temperature: float = 0.1,
        timeout: int = 60,
        connect_timeout: int = 10,
        max_retries: int = 3,
        cache_embeddings: bool = True,
        cache_ttl: int = 3600,
        **kwargs
    ):
        super().__init__(
            model=model or settings.llm.default_model,
            temperature=temperature,
            timeout=timeout
        )
        self.base_url = base_url or settings.llm.ollama_url
        self.embedding_model = embedding_model or settings.llm.embedding_model
        self.connect_timeout = connect_timeout
        self.max_retries = max_retries
        self.cache_embeddings = cache_embeddings
        self.cache_ttl = cache_ttl
        
        self._client: Optional[httpx.AsyncClient] = None
        self._initialized = False
        self._embedding_cache: Dict[str, Dict[str, Any]] = {}
        
        self._metrics = {
            "total_generations": 0,
            "total_embeddings": 0,
            "total_cache_hits": 0,
            "total_cache_misses": 0,
            "total_errors": 0,
            "average_generation_time": 0.0,
            "average_embedding_time": 0.0,
            "last_generation_time": None,
            "last_embedding_time": None,
            "models_available": []
        }

    async def _ensure_client(self) -> None:
        if self._initialized and self._client:
            return
        if self._client:
            await self._client.aclose()
        
        timeout_config = httpx.Timeout(
            timeout=self.timeout,
            connect=self.connect_timeout,
            read=self.timeout,
            write=30.0,
            pool=5.0
        )
        self._client = httpx.AsyncClient(
            timeout=timeout_config,
            follow_redirects=True,
            limits=httpx.Limits(max_keepalive_connections=10, max_connections=20)
        )
        self._initialized = True

    async def generate(self, prompt: str, system_prompt: Optional[str] = None, **kwargs) -> str:
        data = {
            "model": self.model,
            "prompt": prompt,
            "temperature": kwargs.get("temperature", self.temperature),
            "stream": False
        }
        if system_prompt:
            data["system"] = system_prompt

        try:
            response = await self._request("api/generate", data)
            return response.get("response", "").strip()
        except Exception as e:
            raise LLMError(f"Ollama generation error: {e}")

    async def generate_stream(self, prompt: str, system_prompt: Optional[str] = None, **kwargs) -> AsyncIterator[str]:
        await self._ensure_client()
        data = {"model": self.model, "prompt": prompt, "stream": True}
        if system_prompt:
            data["system"] = system_prompt

        url = f"{self.base_url}/api/generate"
        try:
            async with self._client.stream("POST", url, json=data) as response:
                response.raise_for_status()
                async for line in response.aiter_lines():
                    if line.strip():
                        chunk = json.loads(line)
                        if "response" in chunk:
                            yield chunk["response"]
                        if chunk.get("done", False):
                            break
        except Exception as e:
            raise LLMError(f"Streaming generation failed: {str(e)}")

    async def embed(self, text: str, use_cache: bool = True) -> List[float]:
        if use_cache and self.cache_embeddings:
            cache_key = hashlib.md5(text.encode()).hexdigest()
            if cache_key in self._embedding_cache:
                entry = self._embedding_cache[cache_key]
                if (datetime.utcnow() - entry["timestamp"]).total_seconds() < self.cache_ttl:
                    self._metrics["total_cache_hits"] += 1
                    return entry["embedding"]

        self._metrics["total_cache_misses"] += 1
        data = {"model": self.embedding_model, "prompt": text}
        
        try:
            response = await self._request("api/embeddings", data)
            embedding = response.get("embedding", [])
            
            if use_cache and self.cache_embeddings:
                cache_key = hashlib.md5(text.encode()).hexdigest()
                self._embedding_cache[cache_key] = {
                    "embedding": embedding,
                    "timestamp": datetime.utcnow()
                }
            return embedding
        except Exception as e:
            raise LLMError(f"Ollama embedding error: {e}")

    async def health_check_detailed(self) -> Dict[str, Any]:
        result = {"status": "unknown", "models": [], "default_model": self.model}
        try:
            await self._ensure_client()
            response = await self._client.get(f"{self.base_url}/api/tags")
            if response.status_code == 200:
                data = response.json()
                result["status"] = "healthy"
                result["models"] = [m.get("name") for m in data.get("models", [])]
                if self.model not in result["models"]:
                    result["status"] = "degraded"
            else:
                result["status"] = "unhealthy"
        except Exception as e:
            result["status"] = "unhealthy"
            result["error"] = str(e)
        return result

    async def close(self) -> None:
        if self._client:
            await self._client.aclose()
            self._initialized = False
Exemples d'Utilisation
# Initialisation du client
client = OllamaClient(
    model="deepseek-coder:6.7b-instruct",
    embedding_model="nomic-embed-text",
    temperature=0.3,
    cache_embeddings=True,
    cache_ttl=3600
)

# Génération simple
response = await client.generate(
    prompt="Write a Solidity function for a token transfer",
    max_tokens=500
)

# Génération en streaming
async for token in client.generate_stream(
    prompt="Explain reentrancy attacks",
    system_prompt="You are a security expert"
):
    print(token, end="", flush=True)

# Embedding avec cache
embedding = await client.embed("This is a test sentence")
print(f"Embedding dimension: {len(embedding)}")

# Embeddings batch
texts = ["Text 1", "Text 2", "Text 3"]
embeddings = await client.embed_batch(texts)

# Health check détaillé
status = await client.health_check_detailed()
print(f"Status: {status['status']}")
print(f"Models: {status['models']}")

# Statistiques
stats = client.get_stats()
print(f"Total generations: {stats['total_generations']}")
print(f"Cache hit rate: {stats['embedding_cache']['hit_rate']:.2%}")
