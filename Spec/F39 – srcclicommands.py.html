1. Classes, Structures de Données et Commandes Implémentées

Le module src/cli/commands.py constitue l'interface en ligne de commande (CLI) bâtie avec Click. Il fournit un ensemble complet de commandes pour administrer la base de données, piloter le cycle de vie des projets, orchestrer l'exécution des tâches et sprints, et lancer les outils de sécurité[cite: 16].

Commandes de Gestion & Base de Données

def common_options(f):
    """Options communes pour les commandes."""
    f = click.option('--verbose', '-v', is_flag=True, help='Verbose output')(f)
    f = click.option('--quiet', '-q', is_flag=True, help='Quiet output')(f)
    f = click.option('--json', '-j', 'output_json', is_flag=True, help='Output as JSON')(f)
    return f

@cli.command()
@common_options
def status(output_json: bool):
    """Affiche le statut du pipeline."""
    result = {
        "version": "2.0.0",
        "timestamp": datetime.utcnow().isoformat()
    }
    db_ok = asyncio.run(check_db_connection())
    result["database"] = {"status": "connected" if db_ok else "disconnected"}
    
    if output_json:
        click.echo(json.dumps(result, indent=2))
    else:
        click.echo(f"📊 Database: {'✅ Connected' if db_ok else '❌ Disconnected'}")
